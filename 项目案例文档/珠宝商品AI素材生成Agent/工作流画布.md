# 珠宝商品 AI 素材生成 Agent｜工作流画布

## 画布总览

```text
[输入]
商品原图 2–4 张 + 商品资料 + 用途/比例/风格
          │
          ▼
[节点1 商品身份解析]
结构化商品档案、真实性锚点、禁止改变项
          │
          ├─ 信息不足/图片不合格 ─→ [补拍或补填资料]
          ▼
[节点2 生成计划编排]
图片形式、构图、光线、模特部位、输出尺寸
          │
          ▼
[节点3 商品母版处理]
抠图、除尘、遮罩、透明底母版（可选）
          │
          ▼
[节点4 图像生成/编辑]
低成本预览或正式图；每张独立记录模型与版本
          │
          ▼
[节点5 一致性检查]
结构/纹样/材质/比例/佩戴/清晰度风险
          │
       ┌──┴────────┐
       ▼           ▼
 [人工通过]     [淘汰/局部修改]
       │           │
       ▼           └──→ 带原商品锁回到节点4
 [下载/套图交付/保存风格模板]
```

## 节点契约

| 节点 | 输入 | 输出 | 是否允许自动通过 |
|---|---|---|---|
| 商品身份解析 | 原图、规格、保真要求 | `product_identity` | 否，资料缺失需补充 |
| 生成计划编排 | 身份档案、用途、比例、形式、风格 | `shot_plan[]` | 是，需规则校验 |
| 商品母版处理 | 原图、身份档案 | `product_master` | 否，建议人工看一次 |
| 图像生成/编辑 | 母版、构图计划、参考图 | `candidate_image` | 否 |
| 一致性检查 | 原图、候选图、身份档案 | `qa_report` | 否，输出建议而非最终判定 |
| 版本与交付 | 候选图、审核状态、元数据 | `output_version` | 只有人工确认后可交付 |

## 设计说明

- 每张图都携带 `product_id` 与 `parent_version_id`，避免修改时丢失商品约束。
- “预览”和“正式生成”分开，先验证构图，再消耗高质量模型额度。
- 质检节点不负责替用户确认真伪；它只标记风险，最终由店员确认。
- 失败只重试当前张或局部区域，不整批重生成。
