# 珠宝商品 AI 素材生成 Agent

## 1. 项目背景与目标

珠宝商家需要为同一件真实商品持续制作抖音、小红书、电商详情页和私域传播素材。传统拍摄成本高、换场景慢，通用生图又容易改变首饰结构、纹样和比例。因此项目的核心不是“生成好看的首饰”，而是围绕真实商品建立可复用的商品身份锁，批量生成可审核的商品图。

目标：上传 2–4 张多角度原图，填写商品规格与必须保留特征，按用途选择画面形式和风格，生成候选图，自动检查风险，人工确认后下载并沉淀为店铺模板。

> 本文已脱敏，不包含客户名称、密钥、服务器地址或真实经营数据。项目资料中的成本与通过率仅作为待实测指标，不在此虚构结论。

## 2. 产品流程

```text
多角度上传 → 商品资料卡 → 原图质量检查 → 商品精修母版
→ 选择用途/比例/形式/风格 → 低成本预览 → 正式生成
→ 原图对比与一致性检查 → 人工通过/淘汰 → 聊天式局部修改
→ 版本回退、下载、保存为店铺风格模板
```

### 关键能力

- 商品身份锁：固定材质、结构、主石、纹样、链节和比例，风格只改变场景、光线与构图。
- 套图编排：支持白底商品、质感棚拍、场景陈列、模特佩戴、手持展示、微距细节、平铺构图、礼盒陈列等形式。
- 约束式修改：每次修改只作用于指定项，保留原商品约束并记录版本。
- 质量门：对比原图标记结构增减、纹样变化、比例异常、佩戴位置和清晰度问题，低风险结果才进入交付。

## 3. Agent/系统架构

1. **商品解析节点**：读取多角度原图与规格，整理商品身份、真实性锚点和禁改项。
2. **素材编排节点**：根据用途、比例、图片形式和风格，生成结构化构图计划。
3. **图像生成/编辑节点**：调用统一模型网关，区分抠图合成、场景生成和模特佩戴。
4. **一致性检查节点**：使用规则检查与视觉复核，输出风险清单，不直接替用户判定通过。
5. **版本与交付节点**：保存来源图、模型、参数、成本估算、父版本和审核状态。

模型通过适配器接入，避免页面直接绑定单一供应商；首期采用本机任务队列和本地资产目录，后续可替换为云端队列与对象存储。

## 4. MVP 已验证范围

- 完成本机网页骨架、商品资料表、多图上传、8 类图片形式和风格选择。
- 支持单张预览、组合套图、数量控制、预算提示、历史版本和通过/淘汰状态。
- 已接入单张真实生成测试通道；付费调用前显示次数与预算，并禁止自动重试。
- 失败时保留已成功结果与费用估算，避免整批盲目重跑。

当前仍是验证型 MVP：聊天修改、精确比例裁切和自动商品保真评分需要继续增强；正式模型和单件成本必须通过代表性商品盲测后确定。

## 5. 评估与边界

建议用约 30 件、覆盖戒指/手镯/项链/耳饰及复杂纹样的样本做盲测，按商品一致性、细节质感、佩戴自然度、场景美感、修改稳定性和成本速度评分。商品一致性低于门槛的模型不能仅因便宜或好看而进入正式路径。

主要风险：生成模型可能改动细小纹样、误删工艺特征、改变佩戴位置或在多轮修改后漂移。系统因此保留原图并排对比、人工确认和版本回退，不把模型输出直接当作可交付事实。

## 6. 后续计划

1. 商品母版与局部遮罩，减少整图重生成。
2. 自动一致性评分、失败局部重绘和模板复用。
3. 用真实任务统计首轮通过率、重试率、平均成本与耗时。
4. 再建设账号、租户、额度、审计和云端存储，不提前把 MVP 复杂化。
