# 可演示 Demo

## Demo 输入

### 账号信息

```text
一家本地珠宝回收与加工门店，主要服务周边居民。
目标是通过短视频解释回收流程、加工过程和客户常见疑问。
当前只能拍摄门店、工作人员、真实商品和加工过程，不能虚构顾客故事或价格。
```

### 视频逐字稿

```text
很多人想把旧黄金拿来回收，但最担心的是报价不透明。
到店后我们会先确认成色和重量，再把计算过程当面说明。
如果对结果有疑问，可以继续问清楚再决定。
```

### 画面证据

```text
开头是工作人员面对镜头讲话；中段出现称重和记录动作；结尾展示真实商品和门店环境。
没有可靠数据证明该视频是爆款，也没有看到具体价格或检测证书。
```

## 内容解析 Agent 预期输出摘要

```json
{
  "summary": "视频围绕旧黄金回收中的透明度疑虑，使用流程展示建立信任。",
  "evidence_completeness": "medium",
  "mechanisms": [
    {
      "mechanism": "先提出客户担忧，再展示可核验流程",
      "evidence": "逐字稿第1–3句；画面出现称重和记录",
      "application": "可迁移到真实回收和加工流程内容",
      "confidence": "high"
    }
  ],
  "unknowns": ["没有播放、完播和互动数据", "没有具体价格信息"]
}
```

## 脚本生成 Agent 预期输出摘要

```text
核心观点：客户最关心的不是一句“高价回收”，而是计算过程能不能讲清楚。

推荐钩子：旧黄金回收，最怕的不是价格低，而是你不知道价格怎么算出来。

分镜：
0–3秒：人物正面提出疑问；
3–12秒：展示称重、记录和说明动作；
12–20秒：展示真实商品，说明客户可现场核对；
结尾：邀请观众留言具体问题。

待确认：实际计价规则、是否有公开检测流程、门店地址和发布标签。
```

## Demo 验收标准

- 不出现虚构价格、顾客、资质或数据。
- 每条结论能追溯到输入证据。
- 明确列出未知信息。
- 脚本只有一个核心观点。
- 分镜只使用输入中存在或明确标记为待补拍的素材。
