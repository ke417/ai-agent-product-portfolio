# AI Agent & B端产品作品集
> 求职方向：AI产品助理｜B端大模型应用 / Agent工作流

## 简介
本仓库为产品作品集，存放个人B端AI项目的产品方案、业务流程图、原型截图、Agent工作流设计、提示词工程文档与项目复盘。
MVP原型、Agent逻辑验证全部在Codex平台完成；**部分项目已私有化商用交付企业客户**。受客户保密协议约束，正式商用生产环境无法开放公网访问。
为方便直观体验产品逻辑，基于原有方案，在Coze（扣子）复刻精简版Agent演示Demo，无真实客户业务数据。

## 📁 项目目录
### 项目1｜珠宝商品AI素材标准化生成Agent工作流
- 关键词：Agent编排、提示词工程、效果评估
- 项目简述：面向珠宝B端商家的素材生产Agent，自动完成商品信息解析、文案生成、AI绘图提示词构建、输出质检。
- 产出物：PRD文档、Agent工作流画布截图、全套提示词模板、测试案例、效果评估记录
- 成果：商品素材制作效率提升80%
- 案例文档：[珠宝商品 AI 素材生成 Agent](项目案例文档/珠宝商品AI素材生成Agent/项目说明.md)，含[工作流画布](项目案例文档/珠宝商品AI素材生成Agent/工作流画布.md)、[脱敏提示词](项目案例文档/珠宝商品AI素材生成Agent/提示词与变量.md)和[测试边界](项目案例文档/珠宝商品AI素材生成Agent/测试与边界.md)

- 产出物：业务流程图、产品原型、需求清单、项目验收记录
- 成果：简化车间统计流程，降低人工核算差错
- 案例文档：[轻量加工计件系统](项目案例文档/轻量加工计件系统/项目说明.md)

### 项目3｜珠宝门店贵金属抵押台账与到期提醒管理系统
- 关键词：业务流程梳理、需求文档、迭代落地

4. ProcessOn：业务流程图绘制

仓库中图片、文档均做脱敏打码处理；Coze Demo为同逻辑简化演示版本，不接入真实业务数据。
